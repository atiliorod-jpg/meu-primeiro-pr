# Meu Primeiro PR

Este repositório é um projeto de prática para aprender a usar o GitHub.

## O que é um PR?

Um Pull Request (PR) é uma forma de propor mudanças em um projeto.
Você cria uma branch, faz as alterações e abre um PR para revisão.

## Como contribuir

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça suas alterações
4. Abra um Pull Request
