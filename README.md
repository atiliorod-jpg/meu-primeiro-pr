# Meu Primeiro PR

Este repositorio e um projeto de pratica para aprender a usar o GitHub.

## O que e um PR?

Um Pull Request (PR) e uma forma de propor mudancas em um projeto.
Voce cria uma branch, faz as alteracoes e abre um PR para revisao.

## Como contribuir

1. Faca um fork do repositorio
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faca suas alteracoes
4. Abra um Pull Request
